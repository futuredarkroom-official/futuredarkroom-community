# 未来暗房社区

[English](README.md) | [简体中文](README.zh-CN.md)

欢迎来到未来暗房社区！未来暗房是一个引导式学习的技术分享网站：以知识图谱铺设学习路径，引导学习者一步步走。

- 网站：https://futuredarkroom.com
- 在这里可以：提想法、问问题、分享学习成果、参与共建

## 如何留言讨论

1. 点开上方 **Discussions** 标签页。
2. 点 **New discussion**（新建讨论）。
3. 选一个分类，写下你的帖子，就可以了！

## 分类

- **Announcements** — 官方公告
- **General** — 综合讨论
- **Ideas** — 想法建议
- **Q&A** — 提问求助
- **Show and tell** — 作品分享
- **Polls** — 投票
- **中文讨论** — 用中文讨论

欢迎每一位学习者与共建者！
